# 🏠 Home

### Welcome to Tokens to Agents **✨**

{% hint style="warning" %}
**Work in progress.** Pages are being added.
{% endhint %}

Tokens to Agents aims to cover AI as a whole: how models work, the tools and models available, the companies behind them and the news of the field. Every page is built around diagrams; the text explains them for readers who want more detail.

### How this wiki is organized

The wiki follows one path: from the smallest unit a model handles (a **token**, a piece of text) to the most complete system built on it (an **agent**, a model that uses tools to carry out tasks).

* **Foundations:** What a model is, how it learns, what it needs to run (GPU, memory, quantization), how it generates text (tokens, sampling, KV cache) and images (diffusion), how a LoRA specializes it, and a glossary of every term.

### How to use it

* **Sidebar:** Pages are grouped by section, in reading order.
* **Search:** The search bar at the top finds any term or page.
* **Definitions:** Each page defines its terms the first time they appear, or links to the page that does.

{% hint style="info" %}
This wiki is independent and not affiliated with any AI company. Models, specs, prices and defaults change fast: always check official documentation before relying on a number.
{% endhint %}
